# Third-party notices

PaceBar has no third-party code dependencies. Its pacing behavior and visual design are closely adapted from TokenEater, and the following parts follow TokenEater's source:

- The pacing math, workweek interval walk and cooling date (`Sources/PaceBarCore/PacingCalculator.swift`, `WorkSchedule.swift`)
- The zone quips, reproduced verbatim (`Sources/PaceBarCore/PacingModels.swift`)
- Theme preset hex values (`Sources/PaceBar/UI/Theme.swift`)
- The pacing bar, off-time hatch, popover card and menu bar drawing metrics (`Sources/PaceBar/UI/`)

PaceBar's code is written independently; no source file is copied. TokenEater's license follows.
